# Medical Prescription Editor

Editor visual de plantillas de recetas médicas hecho con React + Vite.

Permite posicionar, editar y redimensionar campos dinámicos sobre una plantilla médica, con vista previa en tiempo real e impresión en formato A4.

---

## Características

- Arrastrar campos libremente sobre la plantilla
- Editar datos desde formulario lateral
- Ajustar tamaño de cada campo manualmente
- Vista previa en tiempo real
- Impresión en formato A4 real
- Límites de tamaño para evitar errores de diseño
- Interfaz ligera y rápida (React + Vite)

---

## Cómo funciona

1. Introduces los datos en el panel lateral
2. Posicionas los campos sobre la plantilla
3. Ajustas el tamaño de cada campo si es necesario
4. Imprimes directamente en formato A4

---

## Tecnologías usadas

- React
- Vite
- JavaScript (ES6+)
- CSS (layout A4 personalizado)
